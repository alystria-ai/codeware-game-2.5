# Codeware for Cyberpunk 2077 2.5 (unofficial build)

An unofficial build of [Codeware](https://github.com/psiberx/cp2077-codeware) 1.20.6 that runs on Cyberpunk 2077 2.5, kept here until the official Codeware supports 2.5.

**This is not an official release and not made by psiberx.** Codeware is by psiberx (MIT licence, see [LICENSE](LICENSE)). The 2.5 support comes from the open pull request [psiberx/cp2077-codeware#63](https://github.com/psiberx/cp2077-codeware/pull/63) ("Support game version 2.5"). This build is that pull request plus small changes by the person who first shared the 2.5 build. The files are unchanged from that build.

When an official Codeware for 2.5 is out, use that one instead. This repository will then point to it.

## Install

1. Game 2.5 only. Game 2.31 uses the [official Codeware](https://www.nexusmods.com/cyberpunk2077/mods/7780) 1.20.5.
2. Install [RED4ext](https://www.nexusmods.com/cyberpunk2077/mods/2380) 1.31.0 or newer first.
3. Extract the zip straight into your Cyberpunk 2077 folder (the one with `bin`, `archive` and `r6`). It goes to `red4ext/plugins/Codeware`. Replace the files if Windows asks.
4. Vortex or Mod Organizer 2: add the zip as a mod from a file.

The RED4ext log (`red4ext/logs`) says `Codeware (version: 1.20.6, author(s): psiberx) has been loaded` when it works.
